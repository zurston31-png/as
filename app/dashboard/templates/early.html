* fewer than 30 measured outcomes — shown so the table is not misleadingly tidy, and not evidence. Expectancy net is the column that decides: a score that ranks raw returns correctly but never clears the cost of trading has found a pattern that is real and unprofitable, which is a different thing from an edge. MAE is the worst drawdown from the signal price — a +5% horizon return that first went −30% is not a +5% trade, it is a stopped-out loss.
